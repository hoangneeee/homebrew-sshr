# homebrew-sshr

Homebrew tap for [sshr](https://github.com/hoangneeee/sshr) - A TUI for managing and connecting to SSH hosts.

## Supported Platforms

- macOS Intel (x86_64)
- macOS Apple Silicon (aarch64)

## Installation

```bash
brew tap hoangneeee/sshr
brew install sshr
```

## Development

Install from local formula:

```bash
brew install --build-from-source ./sshr.rb
```

Test the formula:

```bash
brew test sshr
```
